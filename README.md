# Test Aezakmi — тестовое задание Frontend (React + TypeScript)

SPA из трёх разделов по макету: **логин**, **курсы валют** (таблица + график динамики к USD), **карточки** (форма создания/редактирования с превью).

- **Деплой:** https://artem16115.github.io/test-Aezakmi/
- **Репозиторий:** https://github.com/artem16115/test-Aezakmi
- **Демо-доступ:** `demo@example.com` / `demo123` (подсказка есть и на экране входа)

## Возможности

- **Логин** — mock-авторизация без бэкенда, валидация с подсветкой поля и текстом ошибки, logout. Без входа доступна только страница `/login`; после входа пользователь возвращается туда, куда шёл.
- **Курсы валют** — таблица 8 валют с флагами (Course, Surrender, Buy, Change, Time) из открытого API. Клик по строке открывает график динамики выбранной валюты к USD за 1W / 1M / 3M / 6M / 1Y. Выбор валюты и периода хранится в URL (`/rates?currency=EUR&period=1M`) — ссылкой можно поделиться, «Назад» работает.
- **Карточки** — форма на react-hook-form + zod: валидация, теги, картинки (выбор и drag & drop), alert с данными при отправке (имитация запроса). Свой выпадающий список (клавиатура, поиск по буквам, ARIA combobox) вместо нативного `<select>`. Карточки сохраняются в `localStorage`, их можно редактировать и удалять (с окном подтверждения); список превью на `/cards`.
- Состояния loading / error / пусто для всех запросов (скелетоны, ошибка с кнопкой Retry), адаптив desktop / tablet / mobile (1440 → 320 px), доступность с клавиатуры и для скринридеров.

## API курсов валют

Используется **[Frankfurter](https://frankfurter.dev)** — бесплатный открытый API курсов валют. Данные — официальные референсные курсы центробанков (основной источник — Европейский центральный банк), обновляются раз в рабочий день. Ключ и регистрация не нужны, CORS открыт, поэтому запросы идут прямо из браузера.

**Эндпоинт один:**

```
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=AUD,BRL,…&from=YYYY-MM-DD[&group=week]
```

Ответ — массив `[{ date, base, quote, rate }]`, ошибка — `{ status, message }`. Оба формата проверяются zod-схемами (`src/features/rates/api/schemas.ts`); если ответ не похож на ожидаемый, показывается ошибка, а не сломанная таблица.

- **Таблица** — один запрос по 8 валютам за последние 10 дней (`from` = сегодня − 10 дней).
  - **Course** — `rate` на последнюю дату: сколько единиц валюты дают за 1 USD.
  - **Surrender** = Course × 1.02, **Buy** = Course × 0.985 — бесплатные API отдают один средний курс, поэтому спред покупки/продажи имитируется фиксированными коэффициентами (так же посчитаны цифры в макете; константы в `src/features/rates/config.ts`).
  - **Change** — `rate` последней даты минус `rate` предпоследней доступной даты этой валюты, со знаком, 4 знака после запятой.
  - **Time** — не из API: время последнего успешного запроса в браузере (`dataUpdatedAt` TanStack Query), `HH:mm`. Дата в шапке — самая поздняя `date` из ответа.
- **График** — тот же эндпоинт по одной валюте, `from` = сегодня − период. Для 1Y добавляется `group=week` (53 недельные точки вместо ~366 дневных — вид графика тот же). Процент в панели — изменение за период: (последний − первый) / первый × 100.

Кэш TanStack Query — 5 минут; при ошибке запрос повторяется один раз, затем показывается ошибка с кнопкой Retry (в том числе без сети).

## Допущения и упрощения

- **BGN → CNY.** В макете есть болгарский лев, но Болгария с 01.01.2026 перешла на евро, и Frankfurter больше не отдаёт BGN — вместо него юань. Список валют — в `src/features/rates/config.ts`, расширяется одной строкой.
- **Mock-авторизация.** Логин проверяется на клиенте (демо-аккаунт выше), «токен» кладётся в куку `auth_token` на 7 дней (`SameSite=Lax`, `Secure` на HTTPS). Это имитация: в реальном проекте токен выдавал бы сервер в httpOnly-куке, недоступной из JavaScript.
- **Картинки карточек не сохраняются.** В `localStorage` попадают только поля карточки; картинки живут в памяти до перезагрузки страницы (хранить файлы в `localStorage` нельзя из-за лимита ~5 МБ). После F5 ряд картинок в превью скрыт.
- **Alert при отправке формы** — имитация запроса на бэкенд, как просит задание.
- **Правила формы карточки:** Title (обязательно, до 100 символов), Description (обязательно, до 1000), Priority (обязательно), Status / Assignee / Deadline — необязательные, дедлайн не в прошлом; теги — до 10, до 20 символов, без дублей; картинки — до 5 штук, только изображения, до 5 МБ каждая.
- **GitHub Pages.** Приложение живёт по пути `/test-Aezakmi/`: этот путь задан в `vite.config.ts` (`base`) и в `basename` роутера, кука ставится с `path=/test-Aezakmi`. Pages не умеет rewrites для SPA, поэтому при сборке `index.html` копируется в `404.html` — прямой заход и F5 на `/rates`, `/cards/new` открывают приложение. `localStorage` общий для всего домена `artem16115.github.io`.

## Тесты

`npm test` — юнит-тесты на Vitest:

- `src/features/auth/schema.test.ts` — схема логина: правила и тексты ошибок;
- `src/features/cards/model/schema.test.ts` — схема карточки: обязательные поля, длины, дедлайн, теги, картинки;
- `src/features/rates/lib/rates.test.ts` — расчёты: Surrender / Buy, Change, % за период.

## Структура проекта

```
src/
  app/          # App, провайдеры (QueryClient, Auth, Cards), роуты
  pages/        # LoginPage, RatesPage, CardsPage, CardFormPage
  features/
    auth/       # контекст авторизации, защита роутов, форма логина, схема
    rates/      # api/ (запросы + zod), hooks/, lib/ (расчёты), components/ (таблица, график), config
    cards/      # model/ (типы, схема, константы), хранение, контекст, components/ (форма, теги, картинки, превью)
  shared/
    ui/         # Button, TextField, Select, ConfirmDialog, Emoji, Badge, Skeleton, ErrorState и др.
    assets/     # emoji/ — SVG Microsoft Fluent Emoji
    layout/     # AppLayout, Sidebar, MobileNav, PageHeader
    lib/        # куки, localStorage, форматирование
    styles/     # токены, миксины (брейкпоинты), reset, глобальные стили
```

Импорты через алиас `@/` → `src/`. Каждая фича отдаёт наружу только публичное API через `index.ts`.
